# Public source history

This repository begins with the published vst-bench-dataset-host 0.1.0 source snapshot.
The `archive-0.1.0` tag contains the exact imported archive payload. That tag
records an import, not the original development commit. To execute that historical
snapshot, use the original ZIP without Git metadata, as its verifier requires.

- Original source: https://doi.org/10.5281/zenodo.22924073
- ZIP SHA-256: `9a9647478333ea70ec408b6f20330a856c9d3c365c24fdefd4377b1338b9b515`
- Public development begins after this import; earlier development history is
  not included. Attribution and original source-archive identities are preserved.

The 0.1.1 Git checkout uses Git source identity. Its root intentionally has no
`SOURCE-ARCHIVE.json`: that manifest describes the immutable 0.1.0 archive and
would be invalid after changes. Archive verification remains supported for sealed
exports. Release tags and distribution hashes identify later versions separately.

The 0.1.0 DOI identifies 0.1.0 only. Cite the exact tag/commit and distribution
version when using a later release.
